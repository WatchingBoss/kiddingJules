## Python: советы и трюки

### Синтаксис и функции
- **`str.startswith()` с кортежем** — проверка нескольких префиксов в одну строку.
- **Keyword-only аргументы** — добавить `*` в сигнатуру функции.
- **`functools.reduce()`** — применить функцию ко всем элементам итерируемого.
- **`itertools.permutations()`** — все перестановки списка.
- **Функции в словарях** — лямбды и функции как значения.
- **Статические методы** — инкапсулируют логику, часть API класса.
- **`__import__` для определения ОС** — косвенный импорт `sys`.

### Работа со строками и данными
- **Проверка вхождения слова из списка в строку:**
  ```python
  any(word.lower() in st.lower() for word in words)
  ```
- **Чтение файла и trim строк в одну строку:**
  ```python
  print([line.strip() for line in open("filename.txt")])
  ```
- **Замена подстрок через flashtext** — быстрее regex для больших объёмов.

### Асинхронность
- **В async-коде НЕ использовать `time.sleep()`** — блокирует цикл. Использовать `asyncio.sleep()`.

### Pytest
- `pytest --setup-show` — просмотр области применения фикстур.

### requirements.txt
- **Не использовать `pip freeze > requirements.txt`** — добавлять импорты вручную.

### Django
- `select_related()` и `prefetch_related()` — оптимизация запросов.
- Кэшировать сложные запросы.
- Использовать **Django Debug Toolbar** и **Silk** для профилирования.
